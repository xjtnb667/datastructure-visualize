## 摘要

本实验用 NumPy 从零实现了最小二乘法的完整求解流程：构造带截距列的设计矩阵 A，按正规方程
θ = (AᵀA)⁻¹Aᵀy 求参数，其中 (AᵀA)⁻¹ 按要求**自行编写高斯–约当消元法求逆**，未使用
`np.linalg.inv / solve / lstsq`；随后计算全部样本的预测值、残差与均方误差，绘制散点图与
拟合直线，并把求得的 θ 代回正规方程验证。

在真实的房价数据（California Housing，20640 个样本）上：

- 一元线性模型 **ŷ = 1.6838 + 0.0709·x**，**MSE = 1.3008**、**R² = 0.0231**；
- 手写求逆与 `np.linalg.inv` 结果**逐位完全相同**（最大差异 0.000e+00），
  自检 ‖A⁻¹A − I‖∞ = 2.385e−15；
- 任务 7 的验证中 AᵀAθ 与 Aᵀy 的最大差异仅 **6.11e−10**，属浮点舍入误差，
  证明 θ 确实满足正规方程、即残差平方和最小；
- 扩展任务把特征从 1 个增加到 5 个，**MSE 从 1.3008 降到 0.6466（下降 50.29%）**，
  **R² 从 0.0231 升到 0.5144**。

结论：算法实现正确（数值自检全部通过），而一元模型 R² 偏低的原因是
**所选特征与房价的线性相关性本来就弱**（皮尔逊 r = 0.1519），不是最小二乘法算错了 ——
把特征换成相关性更强的收入中位数，同一个求解器给出的 R² 立刻升到 0.4734。

## 五、任务 2：构建设计矩阵 A

### 5.1 模型与矩阵形式

一元线性回归模型：

$$ \hat{y} = \theta_0 + \theta_1 x $$

对第 i 个样本：

$$ \hat{y}_i = \theta_0 \cdot 1 + \theta_1 x_i $$

把 n 个样本的方程竖着排成一列，写成矩阵形式 **Aθ = ŷ**：

$$ A = \begin{bmatrix} 1 & x_1 \\ 1 & x_2 \\ \vdots & \vdots \\ 1 & x_n \end{bmatrix}, \qquad \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \end{bmatrix} $$

第一列全为 1，是给截距 θ₀ 配的"截距列"；第二列是特征 x 的取值。

### 5.2 构造代码

```python
ones = np.ones((x.shape[0], 1))          # 全 1 的截距列
A = np.hstack([ones, x.reshape(-1, 1)])  # 水平拼接，得到 n×2 的设计矩阵
```

### 5.3 结果

```text
A.shape = (20640, 2)   （20640 行 = 样本数 n，2 列 = 参数个数）
```

A 的前 5 行：

| 第 1 列（截距） | 第 2 列 AveRooms |
| --- | --- |
| 1.0 | 6.984127 |
| 1.0 | 6.238137 |
| 1.0 | 8.288136 |
| 1.0 | 5.817352 |
| 1.0 | 6.281853 |

矩阵形状的含义：**行数 = 样本数**（每个样本一个方程），**列数 = 待求参数个数**（θ₀ 和 θ₁），
这正是"n 个方程、2 个未知数"的超定方程组 —— 一般无精确解，所以只能求最小二乘意义下的最优解。

## 六、任务 3：根据正规方程计算模型参数

### 6.1 数学推导

最小二乘问题就是让残差平方和最小：

$$ \min_{\theta}\ \|A\theta - y\|^2 = \min_{\theta}\ \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 $$

把目标函数对 θ 求梯度并令其为 0：

$$ \frac{\partial}{\partial \theta}\|A\theta - y\|^2 = 2A^{\mathsf{T}}(A\theta - y) = 0 $$

整理即得**正规方程（Normal Equation）**：

$$ A^{\mathsf{T}}A\theta = A^{\mathsf{T}}y $$

当 AᵀA 可逆时，两边左乘 (AᵀA)⁻¹：

$$ \theta = (A^{\mathsf{T}}A)^{-1}A^{\mathsf{T}}y $$

由于本实验只有一个特征，所以 **θ 是 2×1 的列向量**，AᵀA 是 2×2 的方阵。

### 6.2 矩阵求逆：自己实现（本任务的关键要求）

任务 3 明确**禁止**使用 `np.linalg.inv()`、`np.linalg.solve()`、`np.linalg.lstsq()`。
本实验在 `code/矩阵工具.py` 中用**高斯–约当（Gauss–Jordan）消元法**自行实现：

思路是对增广矩阵 [M | I] 做初等行变换，把左边化成单位阵，右边就自动变成 M⁻¹：

$$ [M \mid I] \xrightarrow{\text{初等行变换}} [I \mid M^{-1}] $$

具体三步，循环 n 次（第 k 轮）：

1. **列选主元（部分主元）**：在第 k 列的第 k 行及以下，挑绝对值最大的行交换到第 k 行，
   避免用接近 0 的数作除数而放大误差；
2. **主元行归一化**：整行除以主元，使 aug[k, k] = 1；
3. **消元**：用主元行把第 k 列其余各行都消成 0（上下都消，故称"约当消元"）。

核心代码：

```python
def manual_inverse(M, verbose=True):
    M = np.array(M, dtype=float)
    n = M.shape[0]
    aug = np.hstack([M, np.eye(n)])          # 增广矩阵 [M | I]
    for k in range(n):
        p = k + int(np.argmax(np.abs(aug[k:, k])))   # ① 列选主元
        if abs(aug[p, k]) < 1e-12:
            raise np.linalg.LinAlgError("矩阵奇异，不可求逆")
        if p != k:
            aug[[k, p], :] = aug[[p, k], :]          # 交换两行
        aug[k, :] = aug[k, :] / aug[k, k]            # ② 主元行归一化
        for i in range(n):                           # ③ 消去同列其它行
            if i != k and aug[i, k] != 0.0:
                aug[i, :] = aug[i, :] - aug[i, k] * aug[k, :]
    return aug[:, n:], aug
```

**求逆代码的自检**（`python code/矩阵工具.py`）：

- 教科书例子 [[4,7],[2,6]]⁻¹ = [[0.6,−0.7],[−0.2,0.4]]，手写结果一致；
- 与 `np.linalg.inv` 的最大差异：2×2 为 1.11e−16，3×3 为 1.11e−16，5×5 为 5.55e−17，
  10×10 为 2.78e−17，全部达到机器精度。

### 6.3 逐步计算结果

**① 计算 AᵀA**（2×2）：

$$ A^{\mathsf{T}}A = \begin{bmatrix} 20640.000000 & 112054.554679 \\ 112054.554679 & 734686.462350 \end{bmatrix} $$

其中 AᵀA 的左上角元素等于样本数 n = 20640，这是"截距列全为 1"的必然结果，可以当作一个正确性校验点。

**② 计算 Aᵀy**：

$$ A^{\mathsf{T}}y = \begin{bmatrix} 42695.040610 \\ 240745.091790 \end{bmatrix} $$

（Aᵀy 的第 1 个分量就是所有房价之和，第 2 个分量是面积加权后的房价之和。）

**③ 自行编写代码求 (AᵀA)⁻¹**：

$$ (A^{\mathsf{T}}A)^{-1} = \begin{bmatrix} 0.0002817368 & -0.0000429706 \\ -0.0000429706 & 0.0000079150 \end{bmatrix} $$

校验：‖(AᵀA)⁻¹(AᵀA) − I‖∞ = **2.385e−15**（≈0，求逆正确）；
对照：与 `np.linalg.inv` 的最大差异 = **0.000e+00**（逐位完全相同）。

**④ 计算 θ = (AᵀA)⁻¹Aᵀy**：

$$ \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \end{bmatrix} = \begin{bmatrix} 1.683812 \\ 0.070869 \end{bmatrix} $$

AᵀA 的条件数 cond(AᵀA) = **2.1678e+02**，数值上相当稳定，说明用正规方程直接求解是可信的
（条件数不大，浮点误差不会被放大）。

**⑤ 最终的房价预测模型**：

$$ \boxed{\ \widehat{\text{MedHouseVal}} = 1.6838 + 0.0709 \times \text{AveRooms}\ } $$

含义：平均房间数每增加 1 个单位，模型认为房价中位数平均增加 **0.0709**（即约 7090 美元，
因为 MedHouseVal 的单位是 10 万美元）；截距 1.6838 是数学上的常数项，代表特征为 0 时的"基准价"，
现实中不存在房间数为 0 的房屋，故没有实际意义。

### 7.3 残差

$$ e = y - \hat{y} $$

```text
残差数量 = 20640
残差均值 = 0.000000          （最小二乘的性质：残差之和恒为 0）
```

三点解读：

1. **残差均值 = 0.000000（实际为 8.45e−15）**：这是正规方程 Aᵀ(y − Aθ) = 0 的第一个分量

2. **残差与 x 的相关系数 = −6.945e−15 ≈ 0**：说明残差里已经不含能被 x 线性解释的成分，
   线性部分被榨干净了，进一步印证解是最优的；
3. **残差最小值 −9.4513 出现在极端离群样本上**：全部 20640 个样本中残差最负的 5 个是

   | 11862 | 59.875000 | 0.675 | 5.9271 | −5.2521 |
   | 12447 | 62.422222 | 0.875 | 6.1076 | −5.2326 |
   | 1240 | 47.515152 | 0.775 | 5.0512 | −4.2762 |

   可以看出，**残差最大的几个样本全部是 AveRooms 高达 47 ~ 142 的极端离群点**：

   于是产生了 −9.45 这样的大残差。这正是最小二乘法**对离群点敏感**的体现 ——

### 7.4 均方误差 MSE

$$ \text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 $$

```text

RMSE = √MSE = 1.140529
SSE（残差平方和）= 26848.6583
R²   = 1 − SSE/SST = 0.023088
```

**MSE = 1.3008** 是本次实验要求的最终结果。为了判断这个数字算好还是算差，另外计算了：

- **R² = 0.0231**：只能解释房价方差的 2.31%，拟合优度很低；
- 对比"所有样本都猜平均值"这种最笨的模型，我们的 MSE 只降低了 2.31%。

### 7.5 为什么 R² 这么低？（重要，否则会被误认为是代码写错了）

这一节的结论是：**低 R² 来自数据本身，不是最小二乘法算错了。** 证据有三条：

1. **数值自检全部通过**——手写求逆与 `np.linalg.inv` 逐位相同；残差均值为 0；
   残差与 x 的相关系数是 1e−15 量级；任务 7 中 AᵀAθ 与 Aᵀy 的差异只有 1e−10。
   这些都说明求解器本身没有问题；
2. **特征本身与房价的线性相关性就弱**——皮尔逊 r 只有 0.1519，两个变量之间本来就没有强线性关系，
   任何线性模型在这两个变量之间都拟合不出高 R²；
3. **同一个求解器换特征立刻变好**——见第八节补充分析：把特征换成与房价相关性更强的
   MedInc（r = 0.688），同一个 `manual_inverse` + 正规方程代码算出来的 R² 立刻从 0.0231 升到 0.4734。
   代码一行没改，只换了输入列，所以差别只能来自数据。

### 9.1 做法

```python
areas = np.array([1000.0, 1500.0, 2000.0])
A_new = np.hstack([np.ones((areas.size, 1)), areas.reshape(-1, 1)])
pred = A_new @ theta
```

## 十、任务 7：验证正规方程

### 10.1 验证方法

把任务 3 求得的 θ 代回正规方程，看左边 AᵀAθ 与右边 Aᵀy 是否相等；等价地，也可以看
Aᵀ(y − Aθ) 是否为 0。

### 10.2 计算结果

```text
AᵀAθ = [42695.040610, 240745.091790]
Aᵀy  = [42695.040610, 240745.091790]
两者最大绝对差异 = 6.111804e-10

等价检验：Aᵀ(y − Aθ) = [1.694671e-10, 5.256311e-10]
最大绝对分量 = 5.256311e-10
```

### 10.3 结果说明

1. **两边实质上完全相等**。差异只有 1e−10 量级，而 AᵀAθ 和 Aᵀy 的分量都是 1e4 ~ 1e5 量级，
   相对误差约 1e−15，属于**双精度浮点数（约 15~16 位有效数字）的舍入误差**，不是算法错误。
   如果 θ 算错了，这个差异会大到肉眼可见（比如几百甚至几千）。
2. **这个结果说明 θ 确实满足正规方程 AᵀAθ = Aᵀy**，而正规方程本身是由
   "残差平方和 SSE 对 θ 求导等于 0"推出来的，所以满足该方程的 θ 就是**使 SSE 最小的那个解**。
   换句话说：任务 3 用 (AᵀA)⁻¹Aᵀy 直接算出的 θ，与"让误差最小"的 θ 是同一个，
   两种途径互为验证。
3. **几何意义**：A 的列空间是由截距列（全 1 向量）和特征列 x 张成的平面，Aθ 就是 y 在该平面上的
   **正交投影**，残差向量 y − Aθ 垂直于这个平面。Aᵀ(y − Aθ) = 0 正是"垂直"的代数表达 ——
   残差里已经不含任何能被 1 和 x 线性解释的成分，误差降无可降。

## 十一、扩展任务：建立多特征线性模型

### 11.1 选用的特征

指导书要求在有效特征中选不少于 3 个。本实验选了 5 个：

| 序号 | 实际列名 | 中文含义 | 选择理由 |
| --- | --- | --- | --- |
| 1 | MedInc | 街区收入中位数 | 单特征里相关性最强（r = 0.688），代表地段/购买力 |
| 2 | AveRooms | 平均房间数 | 房屋大小/房间数的代理变量（也是基础模型的特征） |
| 3 | HouseAge | 房龄中位数 | 房龄影响价格，且与其它特征相关性低，能提供新信息 |
| 4 | AveOccup | 平均家庭人数 | 反映居住密度 |
| 5 | Population | 街区人口 | 反映街区规模 |

### 11.2 构造新的设计矩阵

$$ A = \begin{bmatrix} 1 & x_{11} & x_{12} & \cdots & x_{15} \\ 1 & x_{21} & x_{22} & \cdots & x_{25} \\ \vdots & \vdots & \vdots & & \vdots \\ 1 & x_{n1} & x_{n2} & \cdots & x_{n5} \end{bmatrix} \in \mathbb{R}^{20640 \times 6} $$

```text
A.shape = (20640, 6)   （1 个截距列 + 5 个特征列）
```

### 11.3 计算模型参数

仍按正规方程 θ = (AᵀA)⁻¹Aᵀy 求解，矩阵求逆继续使用自己实现的 `manual_inverse()`
（扩展任务允许使用现成函数，但沿用自己写的一能保证与主实验口径一致，二来顺便验证
手写求逆在 6×6 规模下依然可靠）：

| 参数 | 取值 |
| --- | --- |
| θ₀（截距） | −0.039805 |
| θ（MedInc） | 0.443247 |
| θ（AveRooms） | −0.025760 |
| θ（HouseAge） | 0.017682 |
| θ（AveOccup） | −0.004688 |
| θ（Population） | 0.0000284 |

模型表达式：

$$ \hat{y} = -0.0398 + 0.4432\,\text{MedInc} - 0.0258\,\text{AveRooms} + 0.0177\,\text{HouseAge} - 0.0047\,\text{AveOccup} + 0.00003\,\text{Population} $$

交叉验证：与 `np.linalg.lstsq` 的最大差异 = **8.447e−14**，说明手写正规方程解在多特征下同样正确。
条件数 cond(AᵀA) = **6.95e+07**，比一元模型的 2.17e+02 大了 5 个数量级 —— 这是**特征量纲差异大**
（MedInc 量级 ~3.9，Population 量级 ~1425）导致的，提示实际工程中应先做标准化；
不过本实验的量级下 8.4e−14 的误差仍可接受。

### 11.4 预测值与误差

```text
MSE  = 0.646590
RMSE = 0.804108
SSE  = 13345.6208
R²   = 0.514408
```

### 11.5 与单特征模型的比较

| 模型 | 特征 | MSE | RMSE | R² |
| --- | --- | --- | --- | --- |
| 一元模型（1 个特征） | AveRooms | 1.300807 | 1.140529 | 0.023088 |
| 多元模型（5 个特征） | MedInc / AveRooms / HouseAge / AveOccup / Population | **0.646590** | **0.804108** | **0.514408** |

- **MSE 下降 50.29%**（降到原来的 49.71%）；
- **R² 提升 0.4913**（从 0.0231 升到 0.5144）。

【插入图3】

图注：**图 3 一元最小二乘模型与多特征模型的误差对比**。左图 MSE 越小越好，右图 R² 越大越好。

### 11.6 结论与分析

1. **多特征模型显著优于单特征模型**：R² 从 0.0231 提升到 0.5144，MSE 减半，
   模型的解释能力从"几乎没有"变成"能解释一半以上的价格差异"。
2. **原因**：房价是由多个因素共同决定的，单特征模型只用一个变量做解释，把其余因素全部塞进残差，
   自然误差大。每增加一个**有效**特征，就多一个可调自由度去逼近真实关系。
3. **注意"有效"二字**：从第 8.3 节的表可以看到，并非特征越多越好 ——
   Population、AveOccup 这类与房价几乎不相关的特征，单独用 R² 都在 0.001 以下，
   它们在本模型中只是提供了极小的补充信息（系数也接近 0，Population 的系数仅 2.8e−5）。
   真正带来提升的主要是 MedInc。
4. **可以继续改进的方向**：先对特征做标准化（消除量纲差异，降低条件数）、
   剔除相关性极低的特征、或者引入非线性项 / 正则化；这些超出本次实验范围，仅作展望。

## 十二、实验结论

1. **推导与实现正确**。最小二乘 → 正规方程 AᵀAθ = Aᵀy → θ = (AᵀA)⁻¹Aᵀy 的推导链条完整；
   按任务要求自行实现的高斯–约当矩阵求逆，与 `np.linalg.inv` 结果逐位相同，
   且通过了 2×2 ~ 10×10 的随机矩阵自检（误差 ≤ 1.11e−16）。
2. **数值结果**。一元模型 ŷ = 1.6838 + 0.0709x，MSE = 1.3008、RMSE = 1.1405、R² = 0.0231；
   任务 7 验证 AᵀAθ 与 Aᵀy 的最大差异 6.11e−10，残差均值为 0（8.45e−15），
   残差与 x 的相关系数为 −6.95e−15 —— 三项独立校验都指向"解是最优最小二乘解"。
3. **对误差的分析**。一元模型 R² 低的原因是特征与目标相关性弱（r = 0.1519）、
   存在极端离群点（AveRooms 最大 141.9）以及目标值被截断在 5.0；
   换成相关性强的 MedInc 后同一个求解器 R² 达 0.4734，证明问题不在算法而在特征选择。
4. **多特征建模有效**。5 特征模型把 MSE 从 1.3008 降到 0.6466（−50.29%），
   R² 从 0.0231 升到 0.5144，说明房价需要多因素共同解释。
5. **工程经验**。学会了处理"库版本 API 变化"（`name=` 参数被移除）、
   "数据集列名与文档不一致"（GrLivArea/SalePrice 不存在）这类真实问题，
   并且明白：数值计算要**用多个独立校验互相印证**（与 numpy 对照、残差性质、正规方程回代），
   不能只看最后的结果数字。
