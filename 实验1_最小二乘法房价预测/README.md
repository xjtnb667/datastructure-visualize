## 三、怎么运行（复现全部结果）

进入 `code/` 目录，依次执行：

```bash
python 矩阵工具.py            # ① 自测手写矩阵求逆（会打印与 numpy 的差异）
python 01_实验主体.py         # ② 任务 0~5、7，结果写入 ../results/
python 02_绘图.py             # ③ 任务 6：三张图
python 03_扩展任务_多特征.py  # ④ 扩展任务：多特征模型对比
python 04_单特征对比.py       # ⑤ 补充分析：各特征单变量回归对比
```

也可以一步跑完（在项目根目录下）：

```powershell
cd code
python 矩阵工具.py; python 01_实验主体.py; python 02_绘图.py; python 03_扩展任务_多特征.py; python 04_单特征对比.py
```

> Windows 下若控制台中文显示为乱码，先执行 `set PYTHONUTF8=1`（PowerShell 用 `$env:PYTHONUTF8="1"`）。
> 结果文件本身都是 UTF-8，CSV 带 BOM，用 Excel 直接打开不会乱码。

## 六、两处需要向批阅老师说明的地方

1. **`fetch_california_housing(name="house_prices", ...)` 在新版 sklearn 会报错。**
   指导书里这个 `name` 参数只存在于较老的 scikit-learn 版本（本机 1.9.1 已移除）。
   `code/数据读取.py` 先按指导书原文调用，捕获 `TypeError` 后自动回退到等价写法
   `fetch_california_housing(as_frame=True)`，新旧版本都能跑通。
2. **指导书里的列名 `GrLivArea` / `SalePrice` 在本数据集中不存在。**
   这两个列名来自 Kaggle 的 Ames 房价数据集，而 `fetch_california_housing` 给出的是
   `AveRooms` / `MedHouseVal` 等列名。本实验按语义就近映射：
   `GrLivArea → AveRooms`（平均房间数）、`SalePrice → MedHouseVal`（价格中位数），
   并在报告第 3.1 节如实写明映射关系。由此带来两个后果，报告中都已说明：
   - 一元模型 R² 偏低（0.0231）是**特征本身相关性弱**（r = 0.1519）造成的，
     报告中用"换特征后 R² 升到 0.4734"做了对照实验证明算法没问题；
   - 任务 5 要求预测的 1000/1500/2000 超出了特征取值范围（0.85~141.9），属外推，
     报告第 9.3 节已如实提示。
